## 📖 프로젝트 소개
**국내 주요 도시 실시간 날씨 지도**는 웹 브라우저 환경에서 대한민국 주요 도시의 실시간 기상 정보를 직관적으로 확인할 수 있는 웹 애플리케이션입니다. 지도 기반 마커 인터페이스를 통해 사용자가 원하는 지역의 날씨 상태를 손쉽게 파악할 수 있도록 제작되었습니다.

👉 **[라이브 데모 바로가기](https://wellove.github.io/aaa/)**

---

## ✨ 주요 기능 (Features)

1. 🗺️ **인터랙티브 도시 마커 표시**
   - 대한민국 주요 도시들의 위치에 마커를 배치하여 지리적 위치와 날씨 정보를 한눈에 연결하여 확인할 수 있습니다.
2. 🌡️ **실시간 날씨 정보 연동 (OpenWeatherMap API)**
   - 마커 클릭 시 OpenWeatherMap API를 호출하여 현재 기온, 날씨 상태, 습도 등 실시간 기상 데이터를 동적으로 가져와 표시합니다.
3. 🎨 **직관적이고 반응형 UI**
   - 깔끔하고 반응형인 디자인을 적용하여 PC와 모바일 기기 모두에서 최적화된 사용자 경험을 제공합니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **API:** OpenWeatherMap API
- **Deployment:** GitHub Pages

## 🚀 시작하기 (Getting Started)

본 프로젝트는 별도의 복잡한 빌드 과정 없이 정적 웹 파일로 구성되어 있습니다. 로컬에서 실행하려면 아래 단계를 따르세요.

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/wellove/aaa.git
   ```
2. 프로젝트 디렉터리 내의 `index.html` 파일을 웹 브라우저로 엽니다.
3. 정상적인 날씨 데이터 조회를 위해 OpenWeatherMap API 키 설정이 필요할 수 있습니다.
